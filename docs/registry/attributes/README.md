# Attribute Registry

- mainframe.adapter.name: The name of the I/O adapter in the form CSS.Chpid.
- mainframe.adapter.owning.partition: The name of the logical partition (LPAR) that owns the I/O adapter when dedicated, or 'shared' when the adapter is shared across partitions.
- mainframe.adapter.type: The type of the mainframe I/O adapter card.
- mainframe.channel.mode: The operating mode of the I/O channel — either dedicated to a single partition or shared across partitions.
- mainframe.channel.name: The name of the I/O channel in the form CSS.Chpid.
- mainframe.channel.owning.partition: The name of the logical partition (LPAR) that owns the I/O channel when dedicated, or 'shared' when the channel is shared across partitions.
- mainframe.cpu.name: The name of the mainframe processor, formed as the processor type abbreviation followed by the processor index number.
- mainframe.cpu.sharing.mode: The sharing mode of the mainframe processor — whether it is dedicated to one partition or shared across multiple partitions.
- mainframe.cpu.type: The type of mainframe processor within the Central Processing Complex (CPC).
- mainframe.host.heatload.type: The type of heat load measurement reported for the Central Processing Complex (CPC).
- mainframe.host.machine_model: The IBM machine model of the Central Processing Complex (CPC), identifying the capacity tier within a machine type.
- mainframe.host.machine_type: The four-digit IBM machine type of the Central Processing Complex (CPC), identifying the hardware generation.
- mainframe.host.power.cord: The identifier of the power cord supplying the Central Processing Complex (CPC).
- mainframe.host.power.phase: The AC power phase supplying the Central Processing Complex (CPC).
- mainframe.host.power.usage.type: The category of power usage measurement reported for the Central Processing Complex (CPC).
- mainframe.host.serial_number: The serial number of the Central Processing Complex (CPC).
- mainframe.host.temperature.type: The location of the temperature sensor within the Central Processing Complex (CPC) frame.
- mainframe.memory.type: The category of mainframe memory being measured within the Central Processing Complex (CPC).
- mainframe.partition.name: The name of the logical partition (LPAR) running on the mainframe.
- mainframe.partition.weight.type: The scheduling weight type that determines how processor time is allocated to the logical partition (LPAR).
- zos.smf.id: The System Management Facilities (SMF) identifier that uniquely identifies a z/OS system within a sysplex or standalone mainframe environment.
- zos.sysplex.name: The name of the z/OS systems complex (SYSPLEX) to which this z/OS system belongs.
