Add virtualization metric groups for common hypervisor and virtual machine telemetry:

- **Hypervisor**: `virtualization.hypervisor.memory.overcommit_ratio`
- **Resource pool**: `virtualization.resource_pool.cpu.allocated`, `virtualization.resource_pool.memory.allocated`
- **Storage pool**: `virtualization.storage_pool.used`, `virtualization.storage_pool.available`
- **Virtual machine**: CPU utilization, ready time, steal time, vCPU count; memory allocated, used, balloon, swapped, and RSS; network I/O; disk I/O, operations, latency, and errors; power state
- **Firmware partition**: CPU utilization, count by type, cumulative CPU time, scheduling weight, capping flag, memory size, and operational state code
