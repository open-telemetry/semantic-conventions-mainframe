Add mainframe metric groups covering the IBM Z Central Processing Complex (CPC) and its logical partitions (LPARs):

- **Channel**: `mainframe.channel.utilization`
- **Processor**: `mainframe.cpu.utilization`, `mainframe.cpu.smt_mode.utilization`, `mainframe.cpu.thread0.utilization`, `mainframe.cpu.thread1.utilization`
- **Host (CPC)**: processor counts by type (active, defective, spare, SAP, IFP), CPU and channel utilization, memory size and VFM metrics, power consumption, temperature, humidity, dew point, heat load, unacceptable status, and adapter utilization
- **Partition (LPAR)**: virtual and reserved processor counts, capping threshold, CPU utilization, z/VM paging rate, power consumption, adapter utilization, operational status (code and unacceptable flag), memory allocation, WLM enablement, DPM processor mode and SMT thread count
