Add metric refinements that extend upstream OpenTelemetry semantic conventions for virtualization entities:

- **Container/VM**: refinements of `container.*` metrics (uptime, CPU time and usage, memory usage, available, RSS, working set, paging faults, disk I/O, network I/O, filesystem available, capacity, and usage) scoped to virtual machine entities
- **Hardware**: refinements of `hw.host.*` (energy, power, ambient temperature, heating margin) and `hw.*` (energy, power, errors, status, network I/O, packets, bandwidth limit and utilization, link up) scoped to the physical virtualization platform hardware and its virtual switch network adapters
- **System CPU and network**: refinements of `system.cpu.time`, `system.cpu.utilization`, `system.disk.limit`, `system.network.io`, `system.network.packet.dropped`, `system.network.packet.count`, and `system.network.errors` scoped to `virtualization.vm`, `virtualization.vswitch`, and `virtualization.storage_pool` entities
