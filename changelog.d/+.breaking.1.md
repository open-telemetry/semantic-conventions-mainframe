Rename `mainframe.lpar.name` to `mainframe.partition.name` and use it as the partition identity of the `zos.software` entity (together with `zos.sysplex.name` and `zos.smf.id`). The attribute applies to logical partitions in both Classic (PR/SM) and DPM mode. Emitters that set `mainframe.lpar.name` on `zos.software` must set `mainframe.partition.name` instead. The z/OS model moves to the Weaver `definition/2` format without other semantic changes.
